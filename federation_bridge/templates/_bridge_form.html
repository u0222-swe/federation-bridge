General
FedHub Connection
CoT Input Receives CoT XML POSTed by a peer bridge or a CDS/guard. Leave the TLS fields below empty for plain HTTP.
Server cert + key = one-way TLS. Add a CA to require and verify a client certificate (mutual TLS).
CoT Output
Each outgoing CoT event is POSTed to this URL. For HTTPS, the cert fields below enable mutual TLS.
Group Handling Carries each event's federation groups through the CoT hop so they survive bridge-to-bridge transit (otherwise lost unless Group Override is set). Adds a non-standard <__fedhubgroups> element to outgoing CoT. Incoming groups are always restored, so enable this on the bridge that emits CoT (the FedHub → CoT / sending side). Group Override, if set, takes precedence over carried groups.
One mapping per line as cot_name = fedhub_name. Incoming CoT groups are translated to the FedHub name before going to FedHub; outgoing FedHub groups are translated back. Unlisted groups pass through.

CoT Transformations — Outbound (FedHub → CoT output) Applied to CoT leaving toward the output (e.g. a CDS): add a callsign marker, redact sensitive elements, stamp a classification.
op:value — op is add-suffix, add-prefix, strip-suffix or strip-prefix. Comma/newline directives: -tag (remove element), -tag@attr (remove attr), tag@attr=value (set attr), zero-point (set point to 0,0 — strips the real location; the marker still displays, at null island). Stamped on event/@access when it is unset or Undefined. preamble=ACCESS — force access when a <remarks> text starts with the preamble.

CoT Transformations — Inbound (CoT input → FedHub) Applied to CoT arriving on the input before it is federated, e.g. strip the callsign marker the far side added.
op:value — op is add-suffix, add-prefix, strip-suffix or strip-prefix. Comma/newline directives: -tag, -tag@attr, tag@attr=value, zero-point (sets point to 0,0 — strips the real location; the marker still displays, at null island). Stamped on event/@access when it is unset or Undefined. preamble=ACCESS — force access when a <remarks> text starts with the preamble.
Simulator
Where simulated events are sent. CoT Output / Both require a CoT Output to be configured.
Virtual Chat Announces a stationary contact (at lat/lon 0,0) into the federation. Any direct chat an ATAK client sends to this contact is re-broadcast as a broadcast GeoChat ("All Chat Rooms") on this bridge's CoT output.
